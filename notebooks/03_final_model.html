Final Model¶

Road Accident Risk Prediction and Safety Prioritization¶

This notebook implements the final predictive modeling workflow for the road-accident risk screening tool.

The final workflow uses:

  • Multiple Linear Regression to estimate continuous accident risk.
  • Logistic Regression to estimate the probability that an observation belongs to the high-risk group.
  • A classification probability threshold of 0.40 for the final high-risk screening decision.

The 0.40 classification threshold was selected during model development because it produced the highest F1 score among the evaluated thresholds while increasing recall compared with the default 0.50 threshold.

This notebook focuses only on the final reproducible modeling workflow. Exploratory analysis and model-development experiments are documented in the earlier project notebooks.

2. Load and Split Data¶

The labeled training dataset is loaded and divided into training and validation subsets.

The id column is excluded because it is an identifier rather than a predictive feature.

A fixed random state is used to make the split reproducible.

4. Final Multiple Linear Regression Model¶

Multiple Linear Regression is used to estimate the continuous accident_risk target.

The preprocessing workflow and regression model are combined in a single pipeline to ensure that the same transformations are applied consistently during training and prediction.

Model performance is evaluated on the held-out validation set using RMSE, MAE, and R².

Regression Result¶

The final regression model achieved a validation R² of approximately 0.804, indicating that the model explains about 80.4% of the variation in accident risk.

Its validation RMSE was approximately 0.0735, substantially lower than the mean-prediction baseline RMSE of approximately 0.1662.

These results support using the regression model as the continuous-risk component of the final screening workflow.

5. Final Logistic Regression Classification Model¶

Logistic Regression is used to estimate the probability that each road condition belongs to the high-risk group.

The high-risk target is defined using the 75th percentile of the training-set accident_risk distribution. Using the training data only to define this threshold prevents the validation target from influencing the classification rule.

The final classification model uses the same preprocessing workflow as the regression model.

Classification Result¶

Using the final probability threshold of 0.40, the Logistic Regression model achieved approximately 89.2% accuracy, 77.3% precision, 80.6% recall, and an F1 score of 78.9%.

The model correctly identified about 80.6% of the actual high-risk validation observations. Compared with the default 0.50 probability threshold, the optimized threshold reduces false negatives and improves recall while maintaining a strong overall balance between precision and recall.

This makes the classification model suitable for the screening objective, where identifying potentially high-risk observations is especially important.

9. Final Model Summary¶

The final road-accident risk screening workflow combines two complementary predictive models.

The Multiple Linear Regression model estimates continuous accident risk and achieved a validation RMSE of approximately 0.0735 and an R² of approximately 0.804.

The Logistic Regression model identifies high-risk road conditions. The high-risk target was defined using the training-set 75th percentile of accident_risk, corresponding to a threshold of 0.46.

For final classification decisions, a probability threshold of 0.40 was used. This threshold produced approximately 89.2% accuracy, 77.3% precision, 80.6% recall, and an F1 score of 78.9% on the validation set.

The final artifacts were saved and successfully reloaded, reproducing the same predictions as the models used during evaluation.

Together, the regression and classification models support the project objective by providing both a continuous accident-risk estimate and a high-risk screening flag for transportation safety prioritization.

This workflow is intended as a proof-of-concept decision-support tool and should not replace professional transportation safety or engineering analysis.
